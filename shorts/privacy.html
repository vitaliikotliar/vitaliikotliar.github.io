Privacy Policy

Last updated: 2 October 2026

What this tool does

Shorts Engine uploads videos created by its owner to the owner's own social media accounts (YouTube, Instagram, TikTok) using the official APIs of those platforms.

Data we access

Only the owner's own accounts are connected. The tool requests the minimum permissions needed to upload videos (for example YouTube youtube.upload, TikTok video.upload / video.publish, Instagram content publishing). It does not read, collect or store data about viewers or any other users.

Website analytics

The public link page (vitaliikotliar.github.io/links/) uses GoatCounter, a privacy-friendly analytics service. It sets no cookies and does not track visitors across sites. It records aggregate page views, referrer, country, browser and device type, and clicks on outbound links. Visitor IP addresses are not stored. This is separate from the upload tool described above.

Storage

OAuth tokens are stored encrypted as GitHub Actions secrets in a private repository and are used only to publish the owner's videos. No data is sold or shared with third parties.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube uploads are subject to the YouTube Terms of Service and Google Privacy Policy.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data retention and deletion

The tool stores no YouTube API data. The only stored item is the owner's OAuth refresh token, which is deleted immediately when access is revoked or the secret is removed. Requests to delete data can be sent to the contact email below and are completed within 7 days.

Revoking access

Access can be revoked at any time at Google account permissions, in TikTok and Instagram app settings, or by deleting the stored secrets.
